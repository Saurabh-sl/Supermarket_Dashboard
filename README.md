# Superstore Dashboard - Power BI

![Dashboard](Dashboard_Supermarket.png)

## 📊 Overview
Analyzed Superstore sales data to track profit, sales and trends using Power BI.

## 🔑 KPIs
- **Total Profit:** 286.40K
- **Total Sales:** 2.30M
- **Profit Margin:** 12.47%

## 💡 Key Insights
- **Top Profitable Products:** Copiers (56K), Phones (45K)
- **Loss Making:** Tables (-18K), Bookcases (-3K)
- **Growth:** Sales increased from 472K in 2015 to 733K in 2017
- **Recommendation:** Focus on Copiers/Phones, review Tables pricing.

## 🛠️ Tools Used
- Power BI Desktop
- Slicers, Cards, Bar Chart, Line Chart, DAX

- .pbix - Power BI Source File
- .pdf - Dashboard Export
